# Built-in sounds

The chimes, class bells and emergency alarm tones are **synthesised by the
application** (`services/sound_generator.py`) the first time it starts and are
stored in the data folder (`%LOCALAPPDATA%\SchoolPagingSystem\library\builtin`).
No third-party recordings are shipped.

Upload your own national anthem, school hymn or custom alarm sounds from the
**Audio Library** module (MP3, WAV, FLAC, OGG, AIFF).
